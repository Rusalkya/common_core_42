## Pages de l'application

Ce que tu dois faire :
- HomePage.jsx : Page d'accueil / Feed des dessins (timeline avec scroll infini)
- LoginPage.jsx : Page de connexion (formulaire email + mot de passe)
- RegisterPage.jsx : Page d'inscription (formulaire email, username, mot de passe)
- ProfilePage.jsx : Page de profil (avatar, bio, dessins de l'utilisateur, bouton ajouter ami)
- PostPage.jsx : Page de détail d'un dessin (image, likes, commentaires)
- ChatPage.jsx : Page de messagerie (liste de conversations + chat en temps réel)
- SettingsPage.jsx : Page de paramètres (modifier profil, changer mot de passe)
- DrawPage.jsx : Page de création de dessin (canvas de dessin + bouton publier)
- NotFoundPage.jsx : Page 404
