## Custom Hooks React

Ce que tu dois faire :
- useAuth.js : Hook pour accéder au contexte d'authentification
- useSocket.js : Hook pour gérer la connexion WebSocket
- usePosts.js : Hook pour charger et gérer les posts (avec pagination)
- useNotifications.js : Hook pour les notifications en temps réel
- useCanvas.js : Hook pour la logique du canvas de dessin
- useDebounce.js : Hook utilitaire pour le debounce (recherche)
